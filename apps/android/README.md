# apps/android — Android 客户端

Kotlin + Jetpack Compose。

## 职责

- 广播自身存在（mDNS）并响应配对
- 文件传输的接收与发送端
- 剪贴板同步
- 扩展屏幕的接收端（P2）
- 被控时的可见授权提示

## 边界

- **投屏与控制不经过本客户端**：由 scrcpy 的 server 端完成。本客户端不重复实现视频采集与输入注入。
- 不实现跨设备键鼠的输入注入（第一阶段）。

## 设备角色差异（方案 2.3）

| | 手机 | 平板 |
|---|---|---|
| 投屏 | 支持（经 scrcpy） | 不适用 |
| 文件 / 剪贴板 | 支持 | 支持 |
| 扩展显示接收 | 不适用 | 目标能力（P2） |
