## 1. IddCx 虚拟显示器安装验证 —— ✅ 已完成（2026-10-30，走方案 A 物理机关闭 Secure Boot）

**结果**：3.2.1 创建 / 3.2.2 取帧 / 稳定性 / `x` 销毁全部通过（3 虚拟显示器、DD 146/50/49 帧 errors=0、非全黑）；结论已回填 `technical-validation.md`——**阶段 4 定向 IddCx 真实第二屏路线**。实测环境坑已记档：`bcdedit testsigning` 被 Secure Boot 策略保护需先关安全启动；Debug 版 App 需补 VC Debug CRT（10 DLL）+ `ucrtbased.dll`（已从 EWDK ISO 拷至 exe 目录）。清理命令：`pnputil /delete-driver oem117.inf /uninstall`（编号 2026-10-30 实测）→ `bcdedit /set testsigning off` → 重启。

**背景**：驱动已用 EWDK 构建并测试签名（微软官方示例原样保留，MIT，驱动代码零改动），仅剩安装验证——对应 `docs/technical-validation.md` §3.2.1 / 3.2.2。结果直接决定阶段 4 走「真虚拟显示器」还是降级「投屏式第二屏」。

**耗时**：约 15 分钟 + 两次重启。**注意**：测试签名期间桌面右下角出现「测试模式」水印，纯提示性，验证完关闭即消失。

> PoC 是独立实验（按规划不进主仓），产物在桌面 worktree 磁盘上：`D:\test\testforai\LinkSpace-desktop\experiments\iddcx-poc\x64\Debug\`。清理 worktree 前请保留该目录。

步骤（PowerShell；标注「管理员」的用管理员窗口）：

1. （管理员）开启测试签名并重启：

   ```powershell
   bcdedit /set testsigning on
   Restart-Computer
   ```

   > **报错「该值受安全引导策略保护」怎么办**（2026-10-30 实测遇到，本机 Secure Boot 开启）：测试签名与 Secure Boot 互斥，二选一：
   >
   > - **方案 A：物理机关 Secure Boot（推荐，验证结果最贴近真实目标环境）**
   >   1. （管理员）`manage-bde -status C:` 查 BitLocker；若显示「保护开启」，先 `Suspend-BitLocker -MountPoint C: -RebootCount 3`（防止固件变更触发恢复密钥询问）
   >   2. （管理员）`shutdown /r /fw /t 0` 直接进 UEFI 设置 → Security/Boot 菜单把 **Secure Boot 改 Disabled**（部分机型需先设置 Supremvisor/管理员密码才能改）
   >   3. 回 Windows 后重跑本步 `bcdedit /set testsigning on`，继续下面流程
   >   4. 全部验证完的第 7 步之后：进 UEFI 把 Secure Boot 改回 Enabled（改之前同样先 Suspend-BitLocker，改完可 `Resume-BitLocker`）；期间内核反作弊游戏会拒绝启动
   > - **方案 B：VMware 虚拟机（完全不动物理机固件）**：VMware 已安装。新建 Win11 虚拟机（固件选 EFI 且关闭 Secure Boot），把 §1 产物（`IddSampleDriver\` 子目录 + `IddSampleApp.exe`）拖进虚拟机，第 2–6 步全部在虚拟机内完成；回填结论时注明「VMware 环境」

2. （管理员）安装驱动包：

   ```powershell
   cd D:\test\testforai\LinkSpace-desktop\experiments\iddcx-poc\x64\Debug
   pnputil /add-driver .\IddSampleDriver\IddSampleDriver.inf /install
   ```

3. **3.2.1 创建**：（管理员）直接运行 `IddSampleApp.exe`，等 20 秒 → 「设置 → 系统 → 屏幕」应出现新显示器；App 控制台打印新增 DXGI 输出的信息。
4. **3.2.1 稳定**：保持运行 10 分钟 → 虚拟显示器不消失；设备管理器中「软件组件 / 间接显示」设备无黄色感叹号。
5. **3.2.2 取帧**：App 创建 SWD 后自动做 8 秒 Desktop Duplication 抓帧，控制台输出 frames / avgInterval / 首帧 BMP 路径与 CRC32、亮度范围。判定：`DuplicateOutput hr=0`、`frames > 0`、BMP 非全黑。
6. **3.2.1 退出**：App 窗口内按 `x` 键 → 虚拟显示器消失，屏幕布局恢复原状。
7. （管理员）清理并恢复正常状态：

   ```powershell
   pnputil /enum-drivers          # 找到 IddSampleDriver 对应的 oem##.inf 编号
   pnputil /delete-driver oem##.inf /uninstall
   bcdedit /set testsigning off
   Restart-Computer
   ```

**回填**：把第 3–6 步的观察（控制台输出 + BMP 路径）回贴给 Agent A，由其回填 PoC README §4 与 `technical-validation.md` §3.2，并给出阶段 4 走向结论。

> 3.2.3（帧传到平板实测延迟）、3.2.4（断网/睡眠恢复）、3.2.5（普通用户安装卸载）不在本轮范围，属阶段 4 正式开发后的验证。
