# modules/protocol — 通信协议

架构 L3 层。

## 职责

- mDNS 服务注册与浏览
- TLS 控制通道（WebSocket）的建连、心跳、断线处理
- 消息信封的编解码与校验
- 错误码映射

## 规范来源

**所有消息定义以 `docs/protocol.md` 为准。** 本目录只放实现，不另立规范。

## 实现要点

- 自签证书 + 指纹绑定（TOFU），首次配对需双方确认
- 拒绝明文降级
- 校验 `v` / `to` / `ts` 窗口 / `from` 已知性，任一失败即断开
- 未知消息类型安全忽略

## 状态

未开始。协议 v0 为草案，v1 发布前不保证兼容。
