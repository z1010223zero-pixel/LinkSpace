# modules/clipboard — 剪贴板同步

架构 L4 层。P1 优先级。

## 职责

- 监听本地剪贴板变化并同步到已授权设备
- 接收远端更新并写入本地剪贴板
- 防循环、防刷屏

## 防循环机制（关键）

消息携带内容摘要（SHA-256 前 16 字节）。接收方若发现摘要与本地最后一次**向外发送**的摘要相同则丢弃。同时维护最近 N 条摘要的滑动窗口，阻断 A→B→A 乒乓。

这是 `docs/mvp-acceptance.md` 6.3 验收项的直接实现。

## 约束

- 第一阶段只做**文本**，图片为后续
- 文本大小上限默认 1 MiB，超限提示而不传输
- **不保存剪贴板历史**（见 `docs/threat-model.md` 第 4 节）
- 日志中禁止出现剪贴板内容
