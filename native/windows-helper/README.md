# native/windows-helper — Windows 原生辅助组件

C# / Win32 辅助进程，**按需拉起、空闲超时退出**，不常驻。

## 职责

承载 Electron 主进程不便直接调用的 Windows 能力，候选：

- 显示器枚举与显示设置查询（为扩展屏与布局服务）
- 输入注入（键鼠共享的 Windows 侧）
- 防火墙规则查询与提示
- 窗口位置与尺寸控制（统一投屏窗口布局时可能需要）

## 边界

- 只提供能力，不含业务决策。决策在 `modules/*`。
- 与主进程之间需定义进程间接口（待定：stdio / 命名管道 / 本地 HTTP）。
- **不承载虚拟显示器驱动**，那是 `native/virtual-display` 的事。

## 状态

未开始。每项能力在引入前应先确认 Electron/Node 侧是否已有可靠方案，避免不必要的原生依赖。
